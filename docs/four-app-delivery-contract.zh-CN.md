# 四 App 统一交付与验收合同

2026-10-21。范围：画布、文档、草图、生图；浏览器 App 不在本轮范围。以各仓当前工作内容的验收分支为基线，保留原分支和未提交工作。完整验收结果另见 `docs/verification/four-app-acceptance-20261021/`；本合同不代表全部实现或正式 MA 接入已经通过。

## 共用规范

1. **交付物分离**：组件包、纯服务端能力、业务服务、数据库/schema、部署配置、CLI/Skill 分别列出。组件安装、App 自身云端闭环、Kit Preview、正式应用登记、真实 Agent 调用、staging 是六道独立门槛。
2. **版本可定位**：每个 App 记录仓库、commit、包名/版本、制品校验和、构建和消费者验证。不得依赖兄弟仓运行目录或隐式 cwd。已有 npm 版本不覆盖发布；新制品通过验收再独立发布。
3. **身份真源一致**：使用 MA 发布的 `/me` 与实例读取合同，由 `@ks-designai/app-authority` 校验 `X-MAV-SSO-Authorization`、`X-MAV-Tenant`、`X-MAV-Application-Instance-Id`。客户端不能通过 actor、用户/租户头、角色头、自报管理员标记绕过验证。
4. **身份不等于写权限**：MA 实例可读只证明身份与可见范围。写入必须有服务端可信动作授权；没有授权默认拒绝。暂由 `createAppWriteAuthorizer(APP_WRITE_GRANTS_JSON)` 提供精确 MA team/biz/user/app/instance + 动作委托，不能通配、不能接受客户端角色，也不维护第二套组织成员表。正式 MA 动作授权合同到位后由适配器接替，不能猜测一个权限接口。
5. **归属贯穿链路**：业务记录、文件、绑定、任务、回执均保留可验证的租户/业务空间/实例映射；先校验归属，再返回内容、版本冲突详情和缓存回执。同团队不同业务空间/实例也不能串读写。后台队列不持久化 SSO 凭据，缺少恢复授权时明确等待/失败。
6. **默认云存储**：持久业务数据以 Appwrite 为权威，生产必须使用明确服务身份和隔离存储配置。缺配置、schema 或授权直接不可用，不静默落本地。`local-test` 仅用于显式隔离测试；缓存清空/服务重启后应从云端恢复。开发者只读策略和正式生产隔离分开说明。
7. **调用信封一致**：统一 manifest 发现、App/实例动作调用、版本化输入、幂等键、状态/回执查询和结构化错误。成功必须给真实结果；异步任务明确 pending/running/succeeded/failed/cancelled 等终态。缺配置/不支持返回显式错误，不造成功数据。
8. **写入可追溯**：修改携带目标版本；同幂等键同输入返回原结果，同键不同输入冲突。写入失败不得提前增加版本或生成虚假回执；重启后幂等记录和任务状态可恢复。公开支持范围不得超过真实实现。
9. **组件边界一致**：surface 接收认证后的 transport/API adapter，不能自建账户体系、直连数据库或读取服务凭据；样式不污染宿主。浏览器专属依赖延迟加载；包声明 React peer、CSS/资源路径和 Provider 输入输出。错误、保存中、冲突、无权限、不可用必须在 UI 可见。
10. **接口与部署边界**：REST/COI/Provider/文件/上传/镜像/CLI 各入口执行同一身份与写策略。CORS 使用明确源；不把静态 token 当共享租户鉴权。单写者限制、任务执行器、上传大小、超时、取消和恢复限制必须写入部署说明。

## 允许保留的业务差异

| App | 权威业务对象 | 必须验的闭环 | 不强行统一的内容 |
| --- | --- | --- | --- |
| 画布 | 画布状态、操作日志、文件与绑定 | 创建→操作→文件→读回→重启恢复；版本冲突、越权、卡种权限 | 状态修订与卡片操作协议 |
| 文档 | 正文与正文修订 | 创建→读取→编辑保存→版本冲突/合并→导出/镜像→重启恢复 | 正文 revision 与画布 revision 不混用 |
| 草图 | 场景快照与内容版本 | 创建→编辑保存→重新打开→画布投影→重启恢复；大列表分页 | Excalidraw 场景格式和快照哈希 |
| 生图 | 图片任务、生成结果与画布交付映射 | 配置/发现→提交→状态→结果云端保存→回填→取消/失败/恢复 | 模型凭据独立于 MA 登录，纯卡包不伪装独立后端 |

## 验收记录要求

每项记录输入条件、使用真实服务或 fixture、命令/请求、真实输出、清理结果和剩余限制。至少覆盖正常路径、同租户只读用户、异租户、同租户跨业务空间、缺 SSO、伪造 actor、授权服务异常、缺云配置、版本冲突、幂等重试、重启恢复。付费生图不因重复验收自动调用模型。

API 格式兼容通过不等于 MA 在线接入；必须用真实 MA 身份、正式应用目录/实例、实际 Agent 调用再单独验。宿主菜单/SDK/编排归宿主 Owner，App 侧做适配，不通过改宿主让验收“变绿”。

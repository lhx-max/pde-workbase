# DesignAI 音频工作台使用手册

易读版 · 2026-11-17 · 当前本地 demo

接手已有视频、台词和配音，完成局部修改、试听检查和交付。先选一句开始，再逐步使用剪辑与混音工具。

平台入口：工作台顶部「使用帮助」。可按目录浏览、搜索关键词或下载 Word。

## 1 快速开始

第一次使用，按这条路径完成一句的修改。

### 先完成一句的编辑

**入口：** 下方台词列表 → 右侧内容编辑

1. 点击一句台词，视频会定位到对应位置，右侧显示本句属性。
2. 点击「当前句放大」，看清该句及附近声音。
3. 先试着调整「本句音量」，再点「本句同步试听」。
4. 核对声音和画面后，点击「确认本句区间」，等待顶部显示「已保存」。

**完成后：** 这句的调整已保存，可以继续编辑下一句，或前往「检查」和「导出」。

**留意：** 如果改的是文字或音色，需要生成配音候选并采用；只改文字不会自动更新声音。

### 找到需要的工具

- 左侧素材与助手：导入视频、配音、台词和背景音乐。
- 中间上方：视频参照、声音波形和剪辑工具。
- 中间下方：浏览台词，选择要修改的一句。
- 右侧：编辑当前句或轨道，查看问题和导出。
- 顶部：保存状态、撤销、重做、使用帮助和主题切换。

### 调整成顺手的布局

**入口：** 顶部工作区与面板分隔线

1. 选择「台词精修」「音频剪辑」或「混音检查」布局。
2. 拖动面板之间的分隔线调整大小；双击分隔线恢复默认尺寸。
3. 左栏可收起；右上角可切换深浅模式。

**完成后：** 面板尺寸与主题会保留在当前浏览器。布局调整不会修改工程内容。

## 2 导入与修改台词

区分文字、声音和音量，避免改完文字却听到旧配音。

### 准备素材

**入口：** 左侧 → 素材

1. 已有完整工程可直接编辑；需要新素材时，选择「导入主视频」「导入整轨配音」或「导入台词」。
2. 台词可用 TXT 或 Markdown 文本；导入后核对分句和时间。
3. 需要音乐时选择「导入背景音乐」；已有音乐时入口变为替换。
4. 只换一句的声音：先选中该句，再点「替换本句音频」。

**留意：** 替换素材后重新试听。「补齐缺失配音」用于没有声音的句子，不会统一更新所有旧配音。

### 改文字或换音色

**入口：** 选中一句 → 右侧内容编辑

1. 修改「台词内容」，或选择「本句音色」。音色可继承整体设置，也可单独指定。
2. 点击「生成本句配音候选」，等待返回。
3. 试听候选，采用满意的结果，再用「本句同步试听」核对画面。

**完成后：** 采用候选后才会换成新声音；生成失败时按提示检查配音服务。

**留意：** 只想调大小声，直接修改「本句音量」即可，无需重新生成。1 为原始倍率，0 为静音。

### 看懂台词状态

- 待更新：旧声音与当前文字或音色记录不一致，需要重新生成或核对。
- 待确认：时间区间需要人工试听核对。
- 已确认：已执行人工确认，不代表系统自动判断内容正确。
- 新增或删除台词：展开右侧「增删台词」；新句仍需内容、声音和有效时间。

**留意：** 需要从视频生成新稿，可通过「打开项目画布」使用改写卡并交付台词，再回工作台精修。视频改写与配音生成分别依赖相关服务。

## 3 移动裁剪与分割

直接在声音片段上操作；先放大，剪完再试听。

### 移动或裁掉一部分声音

**入口：** 选中片段 → 当前句放大

1. 拖动片段中间，将整句移到目标时间。
2. 拖动左边缘裁开头，拖动右边缘裁结尾；松开后提交。
3. 试听结果。需要精调时，展开右侧「时间与音频裁剪」，输入毫秒后按 Enter。

**完成后：** 拖边会同步改变音频源区间与画面区间；原音频文件保留，误操作可撤销。

**留意：** 普通拖动不会推动后续台词。开启「吸附」后会辅助对齐邻近边界或标记；重叠、越界和锁定冲突会被阻止。

### 把一句分成两段

**入口：** 选中片段 → 点击时间刻度定位播放头

1. 把播放头放在该片段有效声音的内部。
2. 点击「分割」或按 S。
3. 在弹窗里调整「台词分句位置」，核对前半句和后半句。
4. 点击「分割并保留原音频」，分别试听两段，再确认区间。

**留意：** 声音按播放头切开，文字按你指定的位置分句；尚未自动按字词对齐。片段边界或静音尾部不能作为有效切点。

### 复制粘贴或删除

**入口：** 选中片段 → 上方工具栏或右键菜单

1. 复制后，把播放头移到足够长的空白位置，再粘贴。
2. 删除会移除当前片段及对应台词，其他片段保持原位置。
3. 误操作点顶部「撤销」；需要恢复撤销的操作时点「重做」。

**留意：** 片段剪贴板仅用于当前工程。粘贴会检查重叠与视频边界；删除片段不会删除原音频文件。

## 4 选区与反复试听

圈出要处理的范围，再比较声音、锁定区间或记录时间方案。

### 圈出一段或多段

**入口：** 时间刻度或音轨空白处

1. 按住鼠标拖动框选；按 Shift 可追加选区。
2. 展开「选区工具 · 音量、节奏与审阅」→「选区与试听」。
3. 需要更准确时，用「标为起点」「标为终点」，或展开「精确输入选区」按秒输入。
4. 「加入当前句」可加入该句范围；「清空选区」退出范围选择。

**留意：** 直接拖动配音片段通常是在移动它。要框选，优先在刻度或空白处拖动。

### 反复听修改的位置

**入口：** 时间轴下方播放控制与选区工具

1. 选择「混合」「原声」或「配音」；有音乐素材时也可单听背景音乐。
2. 用「同步播放」从当前位置听，用「回听 3 秒」重听刚经过的内容。
3. 选区可「按顺序试听」或「循环试听」；「带上下文」可加前后 0.5 秒或 1 秒。

**完成后：** 画面与所选声音同步播放；点击「暂停」结束试听。

### 保护范围或比较时间安排

**入口：** 选区与试听 → 锁定选区或时间方案

1. 对不想误改的范围点击「锁定选区」；需要修改时点对应「解锁」。
2. 将当前安排「存为 A」，调整后「存为 B」。
3. 用「试听 A/B」比较；满意后「采用 A/B」。

**留意：** 时间方案只保存台词的时间区间，不是完整音频、文字或工程的版本备份。

## 5 音量节奏与审阅

先确认处理范围，再调整大小声、停顿或记录返工问题。

### 调整整轨或局部音量

**入口：** 轨道名称，或选区工具 → 音量

1. 整轨：点击「配音音轨」等轨道名称，在右侧调音量；0 dB 为原始音量，负值更轻。
2. 一句：选中台词，在右侧修改「本句音量」。
3. 一段：框选后进入「音量」，选择目标音轨、音量倍率与前后渐变时长，点「应用到选区」。

**留意：** 没有显式选区时可使用当前句范围。「复制音量和渐变」只复制参数。同轨音量区间不能任意重叠；这里的渐变不是片段交叉淡化。

### 调整停顿或对齐转场

**入口：** 选区工具 → 间隔与标记

1. 选中第二句或后面的台词，调整与上一句的停顿。
2. 明确选择「只移动本句」或「本句及后续」，先「试听移动」，再「应用间隔」。
3. 需要对齐画面时「标记当前帧」，之后可「跳到标记」或「本句吸附到标记」。

**完成后：** 只有应用后才保存新的时间安排；应用前先检查影响范围。

### 逐句审阅并留批注

**入口：** 选区工具 → 审阅

1. 选择「核对配音」或「核对字幕」，点击「试听当前」。
2. 确认无误后点「通过并下一句」；不确定可「跳过」。
3. 需要返工时，选择范围、填写批注，再点「添加时间批注」。
4. 处理后标为已处理；可通过批注时间回听，或「附上当前配音」保留参考。

**留意：** 审阅通过与「确认本句区间」是不同记录。勾选通过或已处理不能代替实际修复。

## 6 保存与导出

先等保存完成，再核对交付音轨和文件格式。

### 确认内容已经保存

**入口：** 顶部保存状态

1. 看到「待保存」时继续保留页面，等到「已保存」再离开。
2. 保存失败先点「重试保存」。
3. 仍失败时先「导出草稿」，再决定是否「读取最新」。

**留意：** 读取最新会放弃未保存草稿。撤销历史属于当前页面会话，刷新后不能依赖之前的撤销记录。

### 导出前检查

**入口：** 右上角 → 检查 → 导出

1. 处理台词、配音和时间区间提示，试听修改位置。
2. 核对「交付音轨」：若刚才独听了配音，但要交付混音，先切回「混合」。
3. 选择文件格式并完成导出。
4. 打开成品，复听开头、修改处和结尾，检查声音、画面与字幕。

**留意：** MP4 录制时保持页面在前台，不关闭页面；需要停止时点「取消导出」。

### 选择交付格式

- WAV：交付音频，采用当前音轨与音量设置；本地混音支持 15 分钟以内的视频。
- SRT：交付逐句字幕，使用台词文字和画面时间。
- MP4：交付带画面的成片；一个选区可单独导出，也可导出全片，可勾选画面字幕。依赖浏览器 H.264/AAC 编码能力。
- 剪辑交接包：素材、音轨与工程清单；不是剪映或达芬奇的原生工程。

**留意：** 试听倍速只用于审听，导出仍按原视频时间安排生成。

## 7 遇到问题

先定位是哪一步没有完成，再按对应方法处理。

### 没有台词或右侧没有内容

1. 等待项目加载完成，确认浏览器标签打开的是目标工程。
2. 点击下方列表中的一句。若项目本身没有台词，先导入，或到画布生成并交付台词。

### 改了文字仍听到旧声音

1. 检查这句是否显示「待更新」。
2. 生成本句配音候选，试听并采用，再做同步试听。

**完成后：** 文字修改和替换声音是两个动作；只有采用新配音才会更换声音。

### 没有声音或波形不可用

1. 检查试听模式、整轨音量、本句音量和静音设置，确认播放头进入有效声音区间。
2. 确认音源存在且可播放。波形分析失败时，等待保存后刷新；持续失败再检查格式或重新导入。

**留意：** 波形加载失败不等于音频已丢失。

### 拖不动或不能分割粘贴

1. 检查片段是否锁定、是否与其他句重叠或超出视频。
2. 分割点要在有效声音内部；粘贴位置要有足够长的空白。

**留意：** 先「当前句放大」再操作，避免误拖边缘。

### 提示模型或服务未配置

1. 根据报错区分 AI 助手、视频改写和配音生成，联系维护人员检查对应服务。
2. 已有素材仍可手动编辑；服务恢复后再使用相关生成能力。

**留意：** 不要把服务密钥写入台词、批注或对话。保存失败的处理见「保存与导出」。

## 8 快捷键与能力范围

随用随查；输入文字时保留正常编辑行为。

### 常用快捷键

- 空格：播放或暂停；输入框和普通按钮保留各自行为。
- S：分割当前片段，先把播放头放到有效声音内部。
- Command / Ctrl + C、V：复制、粘贴片段。
- Delete / Backspace：删除选中的片段。
- Command / Ctrl + Z：撤销；加 Shift 为重做。
- Shift 配合框选：追加范围。
- 双击分隔线：恢复该面板默认尺寸。
- Esc：关闭使用帮助，回到编辑。

### 本版本支持什么

- 句级台词与配音编辑、真实波形、移动、裁剪、分割和复制粘贴。
- 范围试听、音量调整、时间标记、人工审阅与本地交付。
- 深浅模式、面板尺寸记忆和工作区布局预设。

**留意：** 尚未提供词级自动对齐、保持音高的时长适配、片段交叉淡化、任意多轨重叠、自动降噪、响度统一、完整候选版本库和后台导出。

### 运行与使用范围

- 当前手册对应本地试运行版本；本机服务启动后才能访问本地工作台。
- 多人协作、云端同步与正式部署需要单独验证，本地保存成功不代表这些能力已开通。
- 平台内点击「使用帮助」可查找步骤，也可下载 Word 手册离线阅读。

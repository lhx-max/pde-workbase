# 卡包接口边界与待验收

GitHub 版同时提供卡内短剧配音编辑器和独立短剧导演工作台。以下边界主要适用于卡内编辑器及参赛适配。

| 项目 | 卡内实现与边界 |
| --- | --- |
| 项目导航、改写交付与逐句列表 | 卡内工作台只编辑当前卡。原演示的跨卡交付、项目导航、MA 对话和便签入口仍在独立工作台。 |
| 媒体持久化 | 画布持久化台词、剪辑参数及素材引用。当前渲染器协议未提供授权的媒体读写口，视频和音频需在本次会话绑定。刷新后可按文件内容恢复；交接包可保存媒体。 |
| 在线改写与配音 | 浏览器可生成改写请求并接受经服务端写回的建议。正式万擎和 MA Agent 需要单独配置与验收。浏览器本机配音依赖已运行的 VoxCPM。 |
| 文件导出 | 浏览器支持 WAV、SRT、剪辑交接包和具备 H.264/AAC 编码时的 MP4。服务端利用 `ctx.files` 保存 SRT 和 EDL。 |
| 宿主依赖 | GitHub 分支复用其 master 已有的卡包登记和锁文件，新增差异在卡包目录内。参赛提交以官方基线检出为准。官方宿主登记和依赖装配按平台合同验收。 |
| 正式验收 | 已有本地隔离验证。Appwrite Functions 实际挂包、云端持久化和团队授权、正式 MA、CI 覆盖率和比赛性能指标需要分别验证。 |

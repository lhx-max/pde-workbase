# 卡包接口边界与待验收

卡包只包含卡内短剧配音编辑器（`card.drama.audio`）。早期依赖画布内部接口的演示能力没有放进卡包：

| 项目 | 卡内实现与边界 |
| --- | --- |
| 旧演示卡与跨卡交付 | 已移除。旧版改写卡、配音列表卡和服务端启动本机 TTS 的动作，依赖请求画布内部 `/api/*`、直接写画布 state，违反卡包合同 §5、§12。旧演示卡数据现在统一由导演卡渲染。 |
| 项目导航、MA 对话、便签入口 | 不在卡包范围。卡片只编辑自身数据，自然语言调用通过画布 Agent 调用卡片动作完成。 |
| 媒体持久化 | 画布持久保存台词、剪辑参数和素材引用。合同 v1 的渲染器没有授权的媒体读写口，视频和音频需要在本次会话中绑定；刷新后按文件内容恢复，或从交接包取回素材。 |
| 在线改写与配音 | 改写由画布 Agent 或 CLI 提交 `card.drama.audio.rewrite`，需要服务端配置万擎。本机配音依赖已在运行的 VoxCPM（`pnpm voice`），且页面须运行于 `127.0.0.1`。 |
| 文件导出 | 浏览器端导出 WAV、SRT、交接包，以及具备 H.264/AAC 编码时的 MP4。服务端动作通过 `ctx.files` 写入 SRT 和 EDL。 |
| 宿主依赖 | 提交到官方基线时，除卡包目录外，还需要 `packs.ts`、`card-packs.ts` 两处注册行，`canvas-workbench`、`apps/server` 各一行依赖声明（与基线参考包 `canvas-pack-demo` 的挂载方式相同），以及 `pnpm-lock.yaml` 中卡包自身的 40 行登记（只增不删，不改动其他包的条目）。这部分需与 Owner 确认。 |

## 待验收

- 用真实画布 Agent 跑通自然语言调用卡片动作（评分「AI 指令可用性」）。
- Appwrite 云端持久化、团队授权与 Appwrite Functions 实际挂包。
- 比赛性能指标实测：首屏可交互、交互帧率、内存、规模上限、导出耗时。
